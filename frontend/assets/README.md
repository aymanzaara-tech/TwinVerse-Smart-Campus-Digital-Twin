# Frontend Assets

This folder contains all assets used by the TwinVerse frontend.

## Folder Structure

- **models/** – Stores 3D models (.glb, .gltf, .fbx, .obj).
- **textures/** – Stores texture images for 3D models.
- **materials/** – Stores material configuration files.
- **hdr/** – Stores HDR environment maps for realistic lighting.
- **images/** – Stores logos, icons, and UI images.
- **references/** – Stores photographs captured for photogrammetry.

## Notes

- Keep assets organized in their respective folders.
- Prefer `.glb` format for 3D models.
